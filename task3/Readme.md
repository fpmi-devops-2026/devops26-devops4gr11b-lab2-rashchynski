# Задание 3. Асинхронная коммуникация в распределенных системах на основе Apache Kafka

## Описание

Данное задание демонстрирует работу с распределенной потоковой системой Apache Kafka в режиме KRaft (без отдельного Zookeeper) с GUI-интерфейсом AKHQ, а также простейшим производителем (Producer) и потребителем (Consumer).

## Компоненты системы

1. **Kafka (Broker & Controller)** — контейнер с Apache Kafka 7.6.0 в режиме KRaft.
2. **AKHQ** — UI-инструмент для мониторинга кластера Kafka (доступен по адресу `http://localhost:8080`).
3. **Producer** — Python-сервис, регулярно публикующий сообщения в топик `test-topic`.
4. **Consumer** — Python-сервис, читающий входящие сообщения из топика `test-topic`.
