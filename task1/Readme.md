# Задание 1: Простейшее распределенное приложение

## Описание

- **Worker 1**: Выбирает случайный файл из каталога `/var/data` и копирует его в `/var/result/data.txt`.
- **Worker 2**: Читает файл `/var/data/data.txt`, находит наибольшее целое число, считает количество его вхождений, записывает полученное количество в `/var/result/result.txt` и выводит результат в консоль (stdout).

## Запуск

```bash
docker compose up --build
```
